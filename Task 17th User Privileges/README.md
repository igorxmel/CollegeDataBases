## Как запустить

Работа сдаётся на колледжном ПК через Open Server Panel и phpMyAdmin. Войти под `root`, на вкладке SQL вставить `17_privileges.sql` и выполнить. Скрипт перезапускаемый: пользователи сначала удаляются. В конце он показывает пользователей и права каждого.

## Права по пользователям

| Пользователь | Пароль | Права |
| --- | --- | --- |
| `admin` | `admin` | все права на все таблицы базы `torgash_Холкин` |
| `oper` | `oper` | просмотр `vids` и `skid`; просмотр и внесение в `salespeople`, `customers_fiz`, `customers_yur`, `orders` |
| `guest` | нет | только просмотр `salespeople`, `customers_fiz`, `customers_yur`, `orders` |

Проверено входом под каждым пользователем. Гость читает `orders`, но получает `INSERT command denied` на вставку и `SELECT command denied` на `vids`. Оператор читает `vids`, получает отказ на `INSERT` в `vids` и на `UPDATE` и `DELETE` в `orders`, а вставка нового юр.лица у него проходит.

## Теоретическая часть

Привилегии определяют, что пользователь вправе делать с объектом базы. Выдаются командой `GRANT`, отзываются `REVOKE`. Привилегия объекта привязана одновременно к пользователю и к таблице: `SELECT` разрешает запросы, `INSERT` вставку, `UPDATE` изменение (можно ограничить столбцами), `DELETE` удаление, `REFERENCES` создание внешнего ключа на эту таблицу. Звёздочка в `ON база.*` значит все таблицы базы, `ON *.*` вообще все базы. После изменения прав выполняется `FLUSH PRIVILEGES`.

## Грабли

**Имя базы с кириллицей берётся в обратные кавычки:** `` `torgash_Холкин`.* ``. Без них команда не разбирается.

**Вставка в `orders` оператором работает, хотя триггер обновляет другую таблицу.** Триггер `orders_after_insert` меняет `customers_fiz`, а у оператора на неё только `SELECT` и `INSERT`. Ошибки нет: триггер выполняется с правами своего создателя, а не пользователя, который вызвал вставку.

**Пароль гостя пустой.** `CREATE USER 'guest'@'localhost'` без `IDENTIFIED BY` создаёт пользователя с пустым паролем, как требует задание. В Open Server Panel пароль `root` по умолчанию тоже пустой.
