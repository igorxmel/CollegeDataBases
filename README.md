Практические работы по базам данных. Здесь лежат мои решения.

Каждое задание живёт в отдельной папке. Внутри исходная методичка и папка `Solution`
с файлами решения.

## Задания

- [Task 2. Подсистема учёта материалов](Task%202)
  Задание демонстрационного экзамена по специальности 09.02.07, вариант 1: база данных
  SQLite и десктопное приложение на Python и tkinter для компании «Мозаика». Просмотр
  списка материалов, добавление и редактирование материала, список поставщиков. Рядом
  лежат материалы всех пяти вариантов ДЭ 2025 года.
